# DR: 同仓库静态双语定价浏览网站

Status: implemented

## Problem

根目录定价表适合机器消费，但直接读取 JSON 难以对比四种费用、上下文阶梯、峰时时段及历史价格。维护者需要完整的中英文在线浏览网站，同时保持单一价格来源，且不向 Git 提交构建产物。

## Decision

> [!NOTE]
> 本决策中的“仅浏览、不包含费用计算器”范围已于 2026-10-12 由 [DR: 网站基础定价金额试算与案例](../implemented/2026-10-12-request-cost-estimator.md) 取代。

网站源码位于 `website/`，使用 Vue 3、TypeScript 和 Vite 构建静态页面。页面提供中英文、人民币/美元、模型家族筛选、名称搜索、价格排序与按模型展开的完整规则。金额试算按上述决策提供基于四项用量的基础定价比较；全部功能在静态页面中运行。

字号通过 `tokens.css` 中的 rem 变量统一管理：正文默认 16px，详情表格规则为 15px、价格为 16px，时段及规则说明为 14px，辅助标签至少 12px。手机端保留这些字号，通过换行及详情表格独立横向滚动适应窄屏，避免把重要信息压缩成小字。

开发服务器和生产构建均从根目录 `model_pricing.json` 读取数据。构建使用根目录 Schema 及额外语义校验，向 `website/dist/model_pricing.json` 输出字节一致的部署副本；源码中不维护副本。运行页面只访问同源数据与资源，部署路径使用相对 URL。根 `.gitignore` 排除依赖、缓存和构建产物，锁文件正常纳入版本管理。

列表按访问时刻选择日期容器的最低有效上下文档位，分别展示非峰时和峰时价格；多峰时价格显示范围，详情逐条展开。每日时间与星期解释固定为 `Asia/Shanghai`（UTC+08:00）。绝对日期区间包含端点，每日区间为左闭右开；选中档位不借用其他节点峰时价。默认价格与全部历史/未来时期均保留浏览入口。

完整 API 名称识别遵守全表 ID、历史别名、正则的优先级与 ASCII 大小写折叠，保留变体身份。子串搜索仅过滤浏览结果，不表示确认同一模型。美元展示由表内汇率换算；所有价格、模型 ID、冻结别名与数据版本均不因增加网站而修改。

`.github/workflows/website.yml` 在拉取请求运行校验与构建，在 GitHub `master` 的相关变更或手动触发时运行数据、身份、决策记录、类型和网站测试，再构建并通过 Pages artifact 发布。仓库已启用 Actions Pages，托管地址为 `https://laoyuehanni.github.io/model-price-table/`；新仓库首次部署需要启用相同的 Pages 来源。

## Alternatives considered

**原生 HTML/CSS/TypeScript。** 依赖更少，但完整规则、双语及多种列表状态需要自行维护 DOM 更新；Vue 组件与类型检查降低多处展示不一致的风险。

**Astro 或逐模型生成静态详情页面。** 有利于搜索引擎收录，但当前目标是集中浏览定价表。单页和模型锚点满足直接定位，避免增加路由和页面生成体系。

**运行时从 GitHub/Gitee 拉取最新 JSON。** 可以独立更新网站数据，但增加跨域、外部网络与源码/数据版本不一致的问题。同一构建的同源部署快照使价格行为可复现。

**提交 dist 或维护 gh-pages 产物分支。** 提交产物造成噪声及重复数据，与用户约束冲突；Actions artifact 将源码历史与部署输出分开。

## Consequences

网站仅靠静态托管即可使用，价格更新与网站代码共享验证和发布过程。单源数据、完整规则展示、中国时区边界及模型身份都有自动检查；新增中文数据标签需要同步补充英文翻译。

网站增加 npm 构建依赖，TypeScript 固定在 Vue 类型检查工具支持的 5.9 系列。每次数据变更仍需重新构建发布，已打开页面刷新后读取新部署数据。页面需要 JavaScript；保留无脚本提示和原始 JSON 下载入口。

网站的中国时区是展示/解析约定，不给原有数据 Schema 增加字段，也不改变其他既有消费者。列表基础档价格不能代表任意上下文请求，页面明确标注该限制，并提供全部档位和时期。
